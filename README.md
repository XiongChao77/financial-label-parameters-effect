# financial-label-parameters-effect
Dissertation title:Parameterized Labeling and Induced Sample Distribution Regimes in Financial Time Series

# Dissertation theme:
This dissertation studies how parameterized labeling reshapes the supervised learning problem in financial time series, first through its effect on label distribution, and second through the resulting effect on machine learning performance.
